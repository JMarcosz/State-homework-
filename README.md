# BasicState

## Descripción
Este proyecto es una aplicación móvil desarrollada en Kotlin para Android. El propósito principal de esta aplicación es explorar conceptos básicos de Jetpack Compose y la gestión de estado en aplicaciones móviles.

## Estructura del Proyecto
El proyecto está organizado de la siguiente manera:

- **app/src/main/java/com/gaby/basicstatecodelab/**: Contiene los archivos principales de la lógica de la aplicación, como `MainActivity.kt`, `WaterCounter.kt`, y otros componentes relacionados con la interfaz de usuario y la lógica de negocio.
- **app/src/main/res/**: Contiene los recursos de la aplicación, como imágenes, valores de cadenas, temas y más.
- **app/src/main/java/com/gaby/basicstatecodelab/ui/theme/**: Define los temas, colores y estilos tipográficos de la aplicación.
- **app/src/main/java/com/gaby/basicstatecodelab/viewmodel/**: Contiene la lógica de ViewModel para la gestión de estado.

## Requisitos
- Android Studio Flamingo o superior.
- Gradle 8.0 o superior.
- Un dispositivo o emulador con Android 8.0 (API nivel 26) o superior.

## Instalación
1. Clona este repositorio:
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   ```
2. Abre el proyecto en Android Studio.
3. Sincroniza el proyecto con Gradle.
4. Ejecuta la aplicación en un dispositivo o emulador.

## Características
- Gestión de estado con Jetpack Compose.
- Componentes reutilizables para la interfaz de usuario.
- Arquitectura basada en ViewModel.
